# 01 — Depth crawl на Canvas

Простейший играбельный прототип «Стигийской библиотеки»: top-down 2D,
один файл, ноль зависимостей. Алгоритм генерации — честный depth crawl
из [docs/stygian-algorithm.md](../../docs/stygian-algorithm.md).

## Запуск

Любой из вариантов:

1. Открыть `index.html` двойным кликом (работает с file://).
2. Статический сервер: `python -m http.server 8000` в этой папке,
   затем http://localhost:8000

## Управление

- WASD / стрелки — движение (русская раскладка тоже работает).
- Дверь срабатывает при подходе вплотную.
- Enter / клик — войти в библиотеку, R — новая экспедиция.

## Дизайн-решения

- **Стек**: vanilla JS + Canvas в одном HTML-файле. Для прототипа
  важнее нулевой порог запуска, чем структура.
- **Комната = экран.** Карта — point-crawl граф комнат, а не тайловый
  мир: это ближе к настольному первоисточнику и проще.
- **Существа не убиваются, от них убегают.** Боёвка не входит в ядро
  depth crawl, поэтому опасность — давление, а не подсистема.

## Соответствие алгоритму книги

| Правило книги                          | Реализация                                        |
|----------------------------------------|---------------------------------------------------|
| Depth растёт при шаге вглубь           | `door.jump` (1, у короткого пути 2)               |
| `1d20 + Depth` по Locations и Details  | `rollTable(LOC/DET, depth)`, таблицы по 30 строк  |
| Бросок Events при входе                | `resolveEvent`: d20 + depth/2, 9 исходов          |
| Point-crawl граф открытых комнат       | `G.rooms` + миникарта по глубинам                 |
| Возврат по графу                       | дверь `back`, комнаты персистентны (сид + id)     |
| Счётчик Progress до порога знания      | `G.progress` 8 → 30: книги, библиотекари, тайники |
| Encounters по глубине                  | три тира существ, тир = depth/4                   |
| Глубже = страннее и опаснее            | сдвиг окна таблиц + тьма/палитра растут с глубиной|

Броски пишутся в журнал (`d20(14)+3 = 17`), чтобы алгоритм был виден.

## Ограничения прототипа

- Геометрия комнат одинаковая, различия — палитра, мебель, детали.
- Нет сохранений, инвентаря, боёвки, звука.
- Баланс (порог 30, HP 12, урон) на глаз, не тестировался всерьёз.
