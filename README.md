# worldsim-stygian-lab

Экспериментальное репо. Здесь мы исследуем процедурную генерацию миров
в стиле depth crawl — на примере «Стигийской библиотеки» (The Stygian
Library, Emmy Allen) — и пробуем перенести эти идеи в worldsim.

Это песочница: код и заметки здесь не являются частью продакшен-агентов.
Удачные находки переносятся в `worldsim-workspace` через обычный процесс.

## Что такое The Stygian Library

OSR-приключение Эммы Аллен (2018): бесконечная междумировая библиотека,
в которую можно попасть из любой достаточно большой земной библиотеки.
Партия обычно приходит туда за конкретным знанием. Карта не нарисована
заранее — библиотека генерируется по мере продвижения вглубь.

## Алгоритм depth crawl

Подробный пересказ — в [docs/stygian-algorithm.md](docs/stygian-algorithm.md).

Кратко:

1. Состояние мира — одно число `Depth` (начинается с 0) плюс растущий
   point-crawl граф уже открытых локаций.
2. Шаг вглубь: `Depth += 1`, затем броски `1d20 + Depth` по таблицам
   Locations и Details, и бросок по таблице Events (может потянуть за
   собой Encounters и Treasure).
3. Чем глубже, тем выше модификатор — верх таблиц «отваливается»,
   открываются всё более странные и опасные результаты. Глубина и есть
   сложность.
4. Открытые локации фиксируются на своей глубине; назад можно вернуться
   по уже построенному графу.
5. Цель отслеживается абстрактным счётчиком Progress: разговоры со
   знающими NPC и найденные книги двигают его к порогу искомого знания.
